Abstract

Vision–language models are built in very different regimes: adapting a frozen billion-parameter LLM with a few million trainable parameters, training a small model end to end to understand every component, or starting from a single pooled CLIP feature as a baseline. These regimes usually live in separate codebases, which makes like-for-like comparisons hard.

Halo-VLM is a self-contained library that hosts all three behind one configuration schema, one model factory and one set of registries. HaleVLM trains about 1% of an 8B model. HaloVLM is a from-scratch model whose vision encoder and decoder both use DeepSeek-style mixture-of-experts layers (about 108M of 289M decoder parameters active per token). BasicVLM prefixes one OpenCLIP feature to a transformer decoder. All three share typed YAML configs, SmolVLM/SmolVLA data registries, a COCO captioning pipeline, and greedy, beam and streaming decoding.

Highlights

One factory

build_vlm(cfg) resolves variant or model.architecture to hale, halo_moe or basic.

HaleVLM

Frozen SigLIP-B/16 → MLP → Qwen3-8B or DeepSeek-R1-Distill-Qwen-7B with LoRA r = 16. Trainable: ≈83.5M or ≈71.6M.

HaloVLM from scratch

ViT (6 layers) + causal decoder (16 layers, 32 heads). Every FFN has 2 shared + 16 routed experts, top-4. 431.5M parameters.

BasicVLM baseline

OpenCLIP ViT-B/32 global token + 12-layer TransformerDecoder (37.9M): the cheapest possible fusion.

Shared data layer

19 SmolVLM datasets by stage, 540 SmolVLA robotics datasets, a robotics → VLM converter, COCO via LAVIS, and overfit sets.

Self-contained

Vendored config, registry and runtime utilities, with no external framework install. CI runs ruff and pytest (29 passed, 2 skipped).

Status and known issues

No benchmark results yet. The HaleVLM path currently overwrites the text after <image> and trains on the whole prompt. See known-issues.md for fixes. The scratch path is unaffected.

Quick start

git clone https://github.com/basaanithanaveenkumar/Halo-VLM && cd Halo-VLM
uv sync --extra dev --extra test --extra scratch
uv run pytest tests/ -q
uv run hale-vlm-train configs/halo_moe_overfit.yaml
from hale_vlm import load_config, build_vlm

model = build_vlm(load_config("configs/halo_moe_coco.yaml"))   # HaloVLM
model = build_vlm(load_config("configs/qwen3_8b_overfit.yaml")) # HaleVLM
